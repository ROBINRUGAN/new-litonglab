# 部署指南

服务器使用 Linux 和 systemd，准备 Python 3.10+、Nginx，开放 80、443 端口。已有环境直接复用；Ubuntu/Debian 缺少的基础依赖由脚本补齐。

## 1. 填写部署信息

在项目根目录打开终端，替换下列信息。附加域名不需要时留空；后台端口选择服务器上的空闲端口。

```bash
bash
set -eu
LAB_SERVER='用户名@服务器地址'
LAB_DOMAIN='官方域名'
LAB_ALIASES=''
LAB_IP='服务器公网IP'
LAB_PORT='8000'
LAB_EMAIL='管理员邮箱'
ssh "$LAB_SERVER" 'true'
ssh "$LAB_SERVER" "ss -lnt 'sport = :$LAB_PORT'"
```

## 2. 检查环境并打包

已有依赖不重复安装，源码未变时复用部署包。

```bash
node -e "const [major, minor] = process.versions.node.split('.').map(Number); if (major < 22 || (major === 22 && minor < 12)) process.exit(1)"
python3 -c 'import sys; assert sys.version_info >= (3, 10)'
npm --prefix frontend ls --depth=0 >/dev/null 2>&1 || npm --prefix frontend ci
npm run check
npm run release
LAB_PACKAGE=$(python3 -c 'import json; print("releases/" + json.load(open("releases/.build-state.json"))["archive"])')
LAB_FILE=$(basename "$LAB_PACKAGE")
LAB_SHA=$(python3 -c 'import hashlib,sys; print(hashlib.sha256(open(sys.argv[1],"rb").read()).hexdigest())' "$LAB_PACKAGE")
```

## 3. 上传部署包

服务器已有相同部署包时跳过上传。

```bash
ssh "$LAB_SERVER" 'mkdir -p ~/litonglab-deploy'
LAB_REMOTE_SHA=$(ssh "$LAB_SERVER" "sha256sum ~/litonglab-deploy/$LAB_FILE 2>/dev/null" | awk '{print $1}')
if [ "$LAB_SHA" != "$LAB_REMOTE_SHA" ]; then
  scp "$LAB_PACKAGE" "$LAB_SERVER:~/litonglab-deploy/$LAB_FILE"
fi
ssh "$LAB_SERVER" "printf '%s  %s\n' '$LAB_SHA' 'litonglab-deploy/$LAB_FILE' | sha256sum -c -"
```

## 4. 安装或更新网站

脚本复用已有 Python、Nginx 和证书；SQLite 过旧时安装官网专用运行库，检查端口，更新前备份数据库与素材。已有账号沿用；首次安装生成管理账号。

```bash
ssh -t "$LAB_SERVER" "cd ~/litonglab-deploy && tar -xOf '$LAB_FILE' deploy/install.sh > install.sh && sudo env LAB_BACKEND_PORT='$LAB_PORT' LAB_DOMAIN_ALIASES='$LAB_ALIASES' LAB_PUBLIC_IP='$LAB_IP' bash install.sh '$LAB_FILE' '$LAB_DOMAIN' '$LAB_EMAIL'"
```

## 5. 配置 HTTPS

先将主域名及附加域名解析到 `LAB_IP`。解析未完成时先跳过本步，完成后手动执行；已有有效证书时直接复用。

```bash
ssh -t "$LAB_SERVER" 'sudo bash /srv/litonglab/current/deploy/https.sh'
```

已有宝塔或其他平台管理的证书时，在服务器的 `/etc/litonglab.env` 中填写以下两项，再执行上面的命令。证书续期由原平台管理。

```ini
LAB_SSL_CERT_FILE=/path/to/certificate/fullchain.pem
LAB_SSL_KEY_FILE=/path/to/certificate/privkey.pem
```

宝塔中的官网位于“网站 → PHP 项目”，PHP 版本为“纯静态”。根目录为 `/srv/litonglab/current/frontend/dist`。管理证书时进入“站点设置 → SSL”，选择 Let’s Encrypt 和 DNS 验证。

## 6. 检查并登录

先检查进程；域名解析完成后检查官网。

```bash
ssh "$LAB_SERVER" 'systemctl is-active litonglab nginx'
ssh "$LAB_SERVER" 'systemctl list-timers litonglab-backup.timer --no-pager'
curl --fail --retry 5 --retry-connrefused "https://$LAB_DOMAIN/api/health/"
ssh -t "$LAB_SERVER" 'sudo sh -c "test ! -f /var/lib/litonglab/initial-admin.txt || cat /var/lib/litonglab/initial-admin.txt"'
printf '官网：https://%s/\n后台：https://%s/admin/\n' "$LAB_DOMAIN" "$LAB_DOMAIN"
```

首次部署登录后，在“修改密码”中设置新密码。以后更新程序重复第 1–6 步。

## 7. 部署位置

| 路径                                           | 用途                                   |
| ---------------------------------------------- | -------------------------------------- |
| `/srv/litonglab/current`                       | 当前程序入口，指向正在使用的版本目录   |
| `/srv/litonglab/releases/`                     | 各版本程序，目录名取部署包的内容校验值 |
| `/srv/litonglab/current/frontend/dist/`        | 构建后的网页、图片、视频、PDF          |
| `/srv/litonglab/tools/`                        | 官网独立运行工具与兼容库               |
| `/var/lib/litonglab/lab.sqlite3`               | 内容、账号和编辑记录数据库             |
| `/var/lib/litonglab/media/`                    | 上传素材                               |
| `/var/lib/litonglab/backups/`                  | 网站备份                               |
| `/etc/litonglab.env`                           | 域名、端口、数据目录和密钥配置         |
| `/etc/nginx/sites-available/litonglab`         | 普通 Nginx 环境的网站配置              |
| `/www/server/panel/vhost/nginx/litonglab.conf` | 宝塔 Nginx 环境的网站配置              |
| `/etc/systemd/system/litonglab.service`        | 官网后台进程                           |
| `/etc/systemd/system/litonglab-backup.timer`   | 每日备份                               |

Nginx 提供网页和素材，将 `/api/` 转发给选定端口的 Django 服务；systemd 管理进程。部署包暂存在登录用户的 `~/litonglab-deploy/`，实际运行入口是 `/srv/litonglab/current`。

```bash
ssh "$LAB_SERVER" 'readlink -f /srv/litonglab/current; systemctl status litonglab --no-pager'
```
